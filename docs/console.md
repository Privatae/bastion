# Local console

`privatae-bastion ui` opens a page served by the running daemon on `127.0.0.1`
and reachable from nowhere else: pairings, the anchor, containment state, marks
on automated programs, the dry-run policy, pending approvals, set-up, what this
machine has given away (where you switch a host's capabilities off), and a
disk map. On Windows a tray icon shows a one-line state. Run as you, it opens
what is waiting for your approval, the console and your context page, and can
stop the bastion. Beside the system service it opens approvals only.
